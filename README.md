# Metadata-Worker

**[English](#english)** | **[Русский](#russian)**

<a id="english"></a>
## English

A comprehensive Python tool for working with Unity IL2CPP global-metadata.dat files. Supports 20+ decryption methods and metadata versions 15-43 (Unity 2015-2026+).
